Communication WiFi ESP32 — Module Drone de Surveillance

Développement d'un module de communication sans fil entre deux cartes ESP32, constituant la brique de base du projet d'essaim de drones de surveillance. L'ESP32 émetteur crée son propre réseau WiFi (Access Point) et transmet des données via UDP à l'ESP32 récepteur, qui les affiche en temps réel sur un écran OLED.

🎯 Objectifs du Projet

  • Établir une communication WiFi directe entre deux ESP32 sans routeur externe.
  • Transmettre des données en temps réel via protocole UDP (faible latence).
  • Afficher les données reçues sur un écran OLED SSD1306 128×64.
  • Valider l'architecture réseau pour le futur essaim de drones de surveillance.

📌 Matériel Utilisé

  • 2× ESP32 DevKit
  • 2× Écran OLED SSD1306 128×64 (I2C — SDA GPIO 21, SCL GPIO 22)
  • Alimentation USB 5V

🛠️ Architecture Réseau

  • ESP32 #1 (Émetteur) — crée un Access Point WiFi (ESP32_RESEAU), IP fixe 192.168.4.1
  • ESP32 #2 (Récepteur) — se connecte au réseau, obtient l'IP 192.168.4.2
  • Protocole UDP sur port 1234 — transmission toutes les 3 secondes
  • Communication I2C avec les écrans OLED (bibliothèque Adafruit SSD1306)

💻 Fonctionnement du Code

ESP32 #1 — Émetteur

  • Crée un réseau WiFi local via WiFi.softAP()
  • Effectue un calcul (extensible à des données capteurs réels)
  • Formate le résultat en chaîne ("42+58=100") et l'envoie via udp.beginPacket()
  • Affiche le résultat et l'état d'envoi sur l'OLED

ESP32 #2 — Récepteur

  • Se connecte au réseau créé par l'ESP32 #1 via WiFi.begin()
  • Écoute en permanence le port UDP avec udp.parsePacket()
  • Lit et décode le message reçu, l'affiche sur l'OLED en temps réel

📷 Images du Projet

⚙️ Schéma de Communication

L'ESP32 #1 génère un réseau WiFi autonome sans infrastructure externe. L'ESP32 #2 s'y connecte et reçoit les paquets UDP. Cette architecture peer-to-peer est directement transposable à une communication drone-station sol ou drone-drone dans le cadre du projet d'essaim de surveillance. Le protocole UDP a été choisi pour sa faible latence, essentielle dans un contexte de commande temps réel de drones.

🔗 Lien avec le Projet Drone

Ce module constitue la couche de communication du projet d'essaim de drones de surveillance. Il sera étendu pour transmettre des données de télémétrie (position, vitesse, état batterie) et des commandes de vol entre les drones et la station de contrôle.
